WP Table Builder is a drag and drop table builder plugin for WordPress. Create beautiful, responsive tables in minutes: comparison tables, pricing tables, product tables, list tables, schedules, and data tables. No coding and no spreadsheet-style configuration screens. Just drag elements into cells and click to edit.

WP Table Builder works with the block editor (Gutenberg), the Classic Editor, and any page builder through a simple shortcode.

## Why WP Table Builder?

Most WordPress table plugins make you build tables in settings screens and preview them somewhere else. WP Table Builder gives you a true visual, drag and drop canvas. What you see in the builder is what your visitors see on the page.

* **Drag and drop editing.** Drop text, images, buttons, ratings, and more into any cell.

* **Fully responsive tables.** Your tables adapt to mobile and tablet screens, with a dedicated responsive mode to fine-tune breakpoints.

* **AI table builder (Pro).** Edit and generate tables with natural language. Describe the change you want and the AI builder makes it.

* **Sortable columns and rows.** Let visitors sort your table data with one click.

* **No lock-in.** Import and export tables as CSV or XML.

## How to Use

1. After you install the plugin, you will see a WP Table Builder menu. Go to WP Table Builder \> Add New.

2. Select the number of columns and rows, then click Generate.

3. Drag and drop elements from the left panel into the table cells and edit them in place.

4. Click Save, then click Embed to copy the shortcode, or insert the table with the WP Table Builder block in the editor.

You can also find the shortcode for every table in the All Tables list under the Table Builder menu.

== FAQ ==

### How do I create a table in WordPress with WP Table Builder?

Install the plugin, go to WP Table Builder \> Add New, choose your rows and columns, and click Generate. Then drag and drop elements like text, images, buttons, and star ratings into the cells. Save the table and embed it anywhere with the shortcode or the WP Table Builder block.

### Can I create a comparison table with this plugin?

Yes. WP Table Builder is built for comparison tables. Combine images, star ratings, feature lists, and buttons in any cell to compare products, services, or pricing plans side by side. Pro users can also start from prebuilt comparison table templates.

### Can I create a pricing table?

Yes. Use lists, buttons, and merged cells to build pricing tables, and highlight your recommended plan with the Pro row and column highlight feature.

### Are the tables responsive on mobile?

Yes. Every table is responsive by default, and a dedicated responsive mode lets you control how tables behave on tablet and mobile: stack cells, keep a static header, enable horizontal scrolling, or hide specific columns on small screens.

### Can I import tables from CSV or Excel?

You can import tables from CSV and XML files, including bulk imports from a zip file. Exporting your Excel sheet as CSV lets you bring spreadsheet data in.

### Can visitors sort the table?

Yes. You can enable sortable columns so visitors can reorder rows by clicking a column header. Pro adds live search and pagination for long data tables.

### Do I need to know how to code?

No. WP Table Builder is a visual drag and drop builder. No HTML, CSS, or shortcode configuration is required, though a Custom HTML element and custom CSS support are there if you want them.

### Does WP Table Builder work with my theme and page builder?

Yes. Tables are embedded with a shortcode or block, so they work with the block editor, Classic Editor, Elementor, Divi, and any other page builder or theme. You can also disable theme styles per table if your theme interferes with table styling.
